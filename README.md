# legal

The privacy policy, the privacy notice for young users and the terms of service of
[Head Up](https://headup.me), in English and Spanish. They are published here so anyone can read them
and see every change. Read them as published on headup.me:

| Text                    | English                                                    | Spanish                                                          |
| ----------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------- |
| Privacy policy          | [headup.me/privacy](https://headup.me/privacy)             | [headup.me/es/privacy](https://headup.me/es/privacy)             |
| Privacy for young users | [headup.me/child-privacy](https://headup.me/child-privacy) | [headup.me/es/child-privacy](https://headup.me/es/child-privacy) |
| Terms of service        | [headup.me/terms](https://headup.me/terms)                 | [headup.me/es/terms](https://headup.me/es/terms)                 |

## Files and versions

| File                                                      | Text                                                    | Versions it states                        |
| --------------------------------------------------------- | ------------------------------------------------------- | ----------------------------------------- |
| `texts/privacy.html`, `texts/privacy-es.html`             | Privacy policy                                          | `privacy-v14`, `privacy-minor-v14`        |
| `texts/child-privacy.html`, `texts/child-privacy-es.html` | Privacy for young users (the notice for minor accounts) | `minor-accounts-v14`, `privacy-minor-v14` |
| `texts/terms.html`, `texts/terms-es.html`                 | Terms of service                                        | `terms-v7`, `terms-minor-v7`              |

Each text states its versions at the top. Every version published in this repository, from the ones
above on, is also a tag of it, and the website and the API pin the tag of the version they publish.
Earlier versions predate this repository.

The files are page sources for the website build. It fills these placeholders and applies the
website's stylesheets: `__APP_NAME__`, `__CONTACT_EMAIL__`, `__PRIVACY_CONTACT_EMAIL__`,
`__LEGAL_CONTROLLER_NAME__` and `__LEGAL_CONTROLLER_POSTAL_ADDRESS__`.

## Questions

Open an issue. Head Up makes every change to the texts itself, so pull requests are not merged.
